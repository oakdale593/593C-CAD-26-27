# 593C-CAD-26-27

Download and install Inventor. If you do not already have an Inventor license, once can be obtained [for free with a valid Student ID](https://www.autodesk.com/education/edu-software/overview#INVPROSA).  
Create a new folder, name as you wish (ie. VEX CAD).  
Download [VEX-CAD/VEX-CAD-Inventor](https://github.com/VEX-CAD/VEX-CAD-Inventor) (Green Code button > Download ZIP) to that folder and unzip the `.zip` file.  
Ensure there is no russian nesting doll folder (move the `VEX-CAD-Inventor-main` folder into the original folder you created if there is a `VEX-CAD-Inventor-main` folder within `VEX-CAD-Inventor-main`).  
Return to the original folder you created, and either `git clone` this repository or just download it as before. If downloaded, ensure no nesting folder.  
Open Inventor, and open the `.iam` assembly file of the subsystem you want to view.  
Profit
